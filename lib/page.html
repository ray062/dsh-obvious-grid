How notifications work

The notify checkbox turns on push notifications for this session only — you'll get a message when it turns idle (finished), errors, or asks for your permission. Alarm sound on this machine is configured with alarmCmd.
1. Type a topic in the ntfy field at the bottom right, e.g. my-dsh-alerts (a long random name keeps it private). It's global — one target for all sessions.
2. Install the ntfy app on your phone and subscribe to that topic — subscribing is what creates it.
